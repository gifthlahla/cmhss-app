# Progress Log — zim-currency-converter

> **Purpose:** Track every completed, in-progress, blocked, or failed task.
> **Rule:** Update this file **before pushing any commit** that completes a `SCOPE.md` task.

---

## Status Key

| Symbol | Meaning |
|---|---|
| ✅ | Verified — tested and working |
| ⏳ | In Progress — task started, not yet tested |
| 🔒 | Blocked — waiting on another task or external dependency |
| ❌ | Failed Testing — needs rework |

---

## Usage Protocol

1. **When starting a task:** Add a row with status `⏳`.
2. **When completing a task:** After testing, update status to `✅` or `❌`, add the commit hash.
3. **When blocked:** Add a row with `🔒` and note the blocker in a comment below.
4. **Never delete rows.** The full history stays visible.
